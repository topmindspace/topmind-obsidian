# Obsidian 写作与 AI 入口体验验收

本文是 4.23.1 的体验记录，不是现行规格。现行交互见 [DESIGN](../DESIGN.md)，操作说明见 [README](../README.zh-CN.md)。

## 问题与处理

| 路径 | 原有断点 | 现在的操作 |
|---|---|---|
| 写作入口 | Ribbon 顺序靠后，动态工具栏同时挤着写作、侧栏、设置、新建笔记 | Ribbon 顶部放“写作与交付”；动态工具栏保留带文字的“新笔记”“写作”，聊天与建议仍从现有导航进入 |
| 写作任务 | 八个动作、输出方式和联网开关同时展开，弹窗过宽 | 常用四项直接选择，其他四项和联网开关按需展开；660px 主弹窗、800px 预览弹窗，窄窗口单列滚动 |
| 写入边界 | 改编或视觉任务可能出现修改源稿的选项 | 只有改稿和纯文字排版可明确选择直接修改；其他任务固定返回建议或成稿，不覆盖源稿 |
| 行内 AI | 选中文字后仍需打开侧栏、解释对象和要求 | 编辑器右键或命令面板执行“AI 审阅选中内容”，绑定当时的笔记、选区、行号与只审阅意图；不写回原文 |
| 新建笔记 | 创建成功后通过路径打开，宿主尚未索引时可能停留在动态 | 等待 Obsidian 索引新文件，随后在新页签打开并显示；动态视图保留，索引超时给出准确提示 |
| AI 建议 | 建议页有“全部确认”和重复的整理入口，误触可能一次执行多项操作 | 移除批量执行和重复整理；逐条建议继续独立确认，刷新建议有文字标签，AI 整理入口收在操作菜单 |

## 实际界面验收

`scripts/smoke-obsidian.cjs` 使用独立临时 Vault、独立应用数据目录和本地模拟 AI 服务商，加载构建后的插件。宿主为本机 Obsidian 1.12.7，插件声明最低版本为 1.13.0，因此这是 UI 与行为冒烟，**不是受支持宿主的正式安装验收**。未使用日常 Vault 或真实模型密钥。

截图和机器记录取自 4.23.1 构建；同一版本通过可复现构建、267 项测试和打包校验。

- Ribbon 能找到“写作与交付”；动态工具栏恰有“新笔记”和“写作”两个文档动作。
- 点击“新笔记”后创建 `00-Inbox/Untitled-*.md`，新笔记成为活跃文件，动态视图仍在原页签。
- 1280×900 窗口下写作弹窗宽 660px；500×560 窗口下宽 400px、高 509px。窄窗口内容区没有横向溢出，底部“开始写作任务”可滚动到达且可键盘聚焦。
- 对 Markdown 选区执行“AI 审阅选中内容”后，副驾回执绑定原笔记与 `topmind-revise` 的 `review` 模式；原文件内容未改变。
- 建议、待办和 AI 对话的既有冒烟路径仍通过；建议页没有“全部确认”；页面异常为零。
