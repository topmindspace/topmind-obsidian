# Obsidian 4.20.1 体验检查

本文是 4.20.1 的体验记录，不是现行规格。现行交互见 [DESIGN](../DESIGN.md)。

## 发现与整改

| 优先级 | 用户遇到的问题 | 本轮处理 |
|---|---|---|
| P1 | 点击 AI 状态点无响应 | 去掉对不存在 label 的依赖，调用真实连接测试；原生按钮支持键盘，测试期间禁用，失败可重试 |
| P1 | 后台聊天会重绘其他标签，打断待办输入 | 进度只更新对话；完成时不重绘其他标签、不抢主编辑器焦点 |
| P1 | 只读总结也显示“1 次写入”，读取路径列为变更 | 移除由路径数量推导写入次数的逻辑；分开工具完成、待确认和引用路径，隐藏空的证据段 |
| P1 | AI 润色返回时覆盖用户刚输入的新内容 | 对比原草稿，变化后保留新文本并提示重新润色；阻止重复请求 |
| P1 | 抓取期间仍可提交，可能产生重复内容；关闭后仍入库 | 共用忙碌状态；关闭后丢弃迟到结果，不执行捕获 |
| P1 | 建议迟到后可能覆盖其他标签，切回又一直加载 | 每次显示使用独立区域，旧响应只可更新自己的区域；重用同一请求供当前建议页接收 |
| P2 | 长对话阅读被重绘拉回底部 | 保存阅读位置，切标签后恢复，提供“回到最新”；隔离旧容器迟到的滚动事件 |
| P2 | 待办超过 20 条只能跳原文件，已完成项只有数量 | 分批加载与未完成筛选，已完成列表可展开并取消勾选恢复；扩大勾选和删除点击区域 |
| P2 | 用键盘切到对话，焦点自动跳进输入框 | 键盘导航保留标签焦点；补齐 tab/tabpanel 关系和完整 tooltip |
| P2 | 清单草稿因切标签丢失，连续录入后失焦 | 保存未提交草稿，成功录入后清空并回到输入框 |
| P2 | 空白回车关闭捕获框；span 的 for 属性没有真正标记表单 | 空白保留弹窗并禁用提交；改用真实 label、补输入名称 |
| P2 | 网址识别不断覆盖手动目的地 | 自动推荐只在用户未选择时生效；普通文字恢复默认，手动选择始终优先 |
| P2 | 插件给整个 Obsidian 原生侧栏涂色 | 移除全局 split/tab chrome 规则和死选择器，交还宿主主题 |
| P2 | 窄主区域的快捷键提示被按钮挤成竖排 | 输入底栏允许换行，提示保留横排，窄面板下操作另起一行 |
| P2 | 未配置 AI 的侧栏只有配置入口 | 提供打开动态的直接操作，保留无需密钥的使用路径 |
| P2 | 输入框用长 placeholder 承担所有教程 | 缩短 placeholder，把键盘提示独立显示并与输入框关联；“上下文”改为“发送对象” |
| P2 | 首次使用说明被单行省略，按钮挤在一起 | 空状态说明可完整换行，使用更清晰的文字颜色和按钮间距 |
| P2 | README 先堆截图、能力和运行时术语，上手路径不清晰 | 中英均先写三分钟开始，再说明安装、AI 配置、日常动作、确认边界和常见故障 |

删除 Desktop 架构页的手写源文件计数，以及“新增一个文件就必须放宽”的精确数量上限；保留模块与插件槽契约检查。

文档测试不再要求每份 README 重复 writeText、CSS 和构建实现细节；这些技术披露集中在 ARCHITECTURE。新增本地链接有效性检查，防止用户点进失效路径。历史审查记录保留其对应版本的事实，不当作当前用户手册。

## 验证方式

执行真实视图与表单的行为测试，并扩展 `scripts/smoke-obsidian.cjs`：从无 AI 的空状态开始，测试键盘 Home/方向键、连接请求、聊天期间在清单录入、对象切换与会话恢复、确认删除、润色期间继续输入、捕获空白/网址目的地，以及窄窗口。

实机脚本使用独立 userData、临时 Vault 和本地模拟服务商，不读取日常 Vault 或真实模型凭证。宿主仍为本机 Obsidian 1.12.7，采用 API 直接加载；声明最低版本保持 1.13.0。该实验不证明 1.13+ 原生设置页、市场安装或真实模型效果全部通过。

本轮结果：

- 插件 typecheck、Lint、250 项测试、build、ZIP 打包与 pack:verify 通过。
- Kernel/跨表面 692 项、UTR 151 项通过；docs:guard 和共享 Agent 契约检查通过；Desktop 源码打包 12 项检查通过，不代表正式安装包已测试。
- 隔离实机覆盖首次无 AI 入口、完整说明换行、键盘标签焦点、真实连接请求、后台待办草稿保护、润色并发输入保护、空白捕获和手动目的地、会话恢复、确认删除、明暗主题及 900px 窄窗口。只读结果不显示写入，动态提示不再竖排，侧栏无横向溢出；另覆盖长消息阅读与回到最新、45 条待办分批/筛选/恢复、建议请求切换标签后的隔离和复用，页面异常为 0。
- 根 `validate` **未全绿**：末次完整检查的 Desktop 快照 1465 项主测试中 1 项失败，为 `workspace-editor-i18n.test.mjs` 的 `zh editor.saveReason`（实际为对象，断言要求字符串）。此前编辑器和大纲的两项源码断言已随并行任务修复；本轮不修改其产品实现，也未把当前失败算成通过。文档手工计数与精确文件数量阈值已清理，插件槽契约仍通过。
- 本地包为 `release/topmind-obsidian-4.20.1.zip`，未发布远端、未装入日常 Vault。

## 发布前复验

4.20.1 最终包重新通过 typecheck、Lint、250 项测试和打包检查。构建显式统一 strict-mode 配置，`npm run build:verify` 在不同目录构建三次，三个安装资产逐字节一致；该检查已接入 CI 和发布流程。

主仓用已发布 Desktop 4.16.4 与 Skills 基线，加上本次所需的共享 Kernel、契约快照和对应测试，建立独立发布候选。该候选完整 `validate` 通过：Kernel/跨表面 689 通过、2 跳过，UTR 151 通过，Desktop 1419 项主测试与 37 项 TypeScript 测试全部通过，构建及源码打包 12 项检查通过。此结果仅验证本次依赖提交，不代表并行中的 Desktop 编辑器重构已经发布。

最终构建再次通过隔离 Obsidian 冒烟测试，页面异常为 0；上方截图及机器证据已更新为这次运行。宿主仍为 1.12.7 直接加载，本地模拟服务商，受支持版本的正式安装矩阵和真实模型效果仍待验收。

## 后续应加强

- 在声明支持的 1.13+ 宿主正式跑设置、安装与升级矩阵；不能用旧宿主直接加载代替。
- 本轮已用 40 条长消息和 45 条待办验证阅读保持、分批加载与筛选；更大规模仍需性能测量，再决定是否需要虚拟列表。
- `styles.css` 仍有历史级联，后续应按组件合并并保留主题视觉回归，避免继续追加覆盖层。
- UI 的路径引用不等于写入证据。原生 Agent 迁移时应携带明确的读/写/待确认结果，再提供更精确的变更明细。
- 当前未发送草稿保留在视图生命周期内，不承诺应用退出后的草稿恢复。需要长期保留的内容请先记录到动态或笔记。
